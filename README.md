# 생각하는 질문노트 · 교사용 가이드 웹앱

『생각하는 질문노트 교사용 가이드북』(2026)을 바탕으로 만든 교사용 웹앱입니다.
미래교육창작소

## 사용 방법

`index.html` 하나로 동작합니다. 내려받아 브라우저(크롬·엣지)로 열면 됩니다.
GitHub Pages를 켜면 웹 주소로도 열 수 있습니다.
(Settings → Pages → Branch: `main` / `/ (root)` → Save)

## 주요 기능

- **대시보드**: 질문노트의 핵심, 질문의 계단(블룸 6단계), 아이보 안내, 최근 워크시트 기록, 아이보의 TIP
- **질문노트 · 블룸**: 단계별 학생 질문·교사 발문 예시, 발문 만들기, 학생 질문 단계 판별과 심화 질문 제안
- **수업 흐름**: 수업 전·중·후 단계 카드와 선생님 실천 TIP
- **학교급 TIP**: 초등 저학년·고학년·중학교
- **수업 사례**: 질문노트 작성 예시(저학년·고학년), 가이드북 수업 사례 3가지, 내 수업 사례 직접 쓰기
- **FAQ**
- **워크시트 1·2·3**: 작성·임시 저장·기록 저장, 텍스트 복사, PDF·JPG 저장
- **칠판 모드**: 교실 화면에 블룸 단계·01/02칸 안내·비판적 수용 발문을 크게 띄우고 타이머 사용

## 참고

- 워크시트와 내 수업 사례는 사용하는 브라우저에만 저장됩니다. 다른 기기와 공유되지 않습니다.
- PDF·JPG 저장은 변환 도구를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
- 'AI로 더 정교하게' 심화 질문 기능은 claude.ai에서 열었을 때만 동작합니다. 그 밖의 환경에서는 기본 심화 질문이 자동으로 나타납니다.
- 우리아이AI: https://wooriai.use.go.kr
